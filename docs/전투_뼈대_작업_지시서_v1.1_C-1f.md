## 0. 규칙 (v1 §0 그대로) + 이번 전용 셋

1. **애니메이션은 그림, 판정은 서버 호 데이터.** 모델·애니를 넣어도 `apply_hit`·호(弧)·캡슐·허용치는 한 줄도 안 바뀐다. 애니 재생 속도를 선딜+활성 시간에 맞추지, 그 반대는 금지.
2. **임시 모델이다.** KayKit은 플레이스홀더. 아트 방향(로아풍)과 무관하고 나중에 통째로 교체된다. 모델 교체가 한 곳에서 끝나게 `CharacterVisual` 같은 층 하나 뒤에 둔다.
3. 소단계 C-1f-1 → f-2 → f-3 순서. 각각 보고·커밋·정지. `reports/C-1f-N.md`.

## 2. 소단계

### C-1f-1 — 조작 (코드만, 모델 없이)
- 좌클릭 체인: 기본 배치 칸1 횡베기(좌→우), 칸2 횡베기 2타(우→좌, 같은 SkillDef에 `chain_variant` 반전 호), 칸3 종베기 올려치기(아래→위, 공중 띄움 = 힘 이벤트 위쪽 보정 재사용). 칸4 비움.
- 체인 창: 현재 기술 후딜의 앞 60% 안에 좌클릭 → 후딜 생략, 다음 칸 시전. 창 지나면 체인 리셋(다시 1타). 체인 타수·창 비율 슬라이더.
- 후딜 이동 캔슬: 후딜 중 우클릭 이동 → 즉시 이동 상태. 선딜 중은 무시(기존).
- 런지 찌르기: 수평 속도 ≥ `lunge_speed_threshold`(기본 4 m/s, 슬라이더)일 때 좌클릭 → 찌르기. 전진 1.5m는 DASH 상태 머신의 거리 파라미터 버전, 새 상태 금지. 관통: 판정이 첫 명중에서 멈추지 않음(SkillDef `pierce=true`).
- 흘리기 키 분리(기본 F, 사용자 지정). 방패 4·잡기·돌진·점프 키 유지.
- 평타 범위 표시 제거. 스마트키 설정은 비평타 기술에만 남김.
- 선·후딜 임시값 적용.
- **검사 C1f1**: 좌클릭 3연타 → 칸1·2·3 순서·호 방향, 창 밖 클릭 → 1타 리셋, 후딜 중 이동 → 후딜 시간 미만에 이동 시작, 선딜 중 이동 → 무시, 달리기 좌클릭 → 찌르기·전진 1.5±0.1m·일렬 허수아비 2개 동시 명중, 정지 좌클릭 → 횡베기, 흘리기 키 → 기존 C1b 흘리기 검사 통과, 2피어, 80ms 프록시.

### C-1f-2 — 모델·애니·메시
- `assets/placeholder/kaykit_adventurers/` 의 Knight(glb) 도입. 캡슐 콜라이더·높이·종족 키 스케일은 그대로, 모델만 캡슐에 붙임. 종족별 키는 모델 스케일로.
- 애니 매핑(KayKit 클립 이름은 파일 보고 맞춤): idle, walk, run, jump, fall, dash(run 가속), slash 수평(횡 1타·2타는 반전 재생), slash 수직/올려치기(종), thrust(찌르기), block(방패 들기), hit, death, grab/carry(들기). 없는 건 가장 가까운 걸로 쓰고 목록으로 보고.
- 재생 속도 = 클립 길이 / (선딜 + 활성). 후딜은 클립 끝 정지 or idle 블렌드. 캔슬 시 즉시 블렌드.
- 검 막대 → 검 메시(KayKit 검 또는 비율 박스: 길이 1.0, 폭 0.08, 손잡이 0.2). 방패도 비율 메시. **호 판정·잔상은 기존 그대로**, 메시는 손 본에 부착.
- 원격 바디도 같은 애니(기존 위상 복제 경로).
- **검사 C1f2**: 모든 C-1 회귀 0 실패(판정 불변 증명), 애니 상태 ↔ 서버 상태 일치(IDLE/RUN/DASH/AIRBORNE/DOWNED/DEAD/공격 중), 재생 속도가 선딜+활성과 ±1프레임, 2피어 원격 애니 동기.

### C-1f-3 — 소리
- 임시 효과음 3개(휘두름·타격·피격) + 방패 막기 1 + 발소리. CC0(kenney.nl 등)로 에이전트가 받을 수 있으면 받고, 못 받으면 멈추고 파일 요청. 기존 사운드 훅에 스트림 연결만.
- 히트스탑 기본값을 3 → 4프레임으로 올려 둠(슬라이더).
- **검사 C1f3**: 타격 시 재생 이벤트 1회, 스위치 끄면 0회.
