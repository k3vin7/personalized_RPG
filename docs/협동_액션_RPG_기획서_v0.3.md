## 1. 개요와 핵심 철학

1\~4인 실시간 협동 PvE 액션 RPG다. 무기 조합이 전투 스타일을, 행동과 수련이 성장을, 성장이 갈 수 있는 곳을 결정한다. 한 줄 콘셉트는 "친구와 함께 하는 엘든링, 대신 각자의 빌드가 서로를 필요로 하는 게임"이며, 주인공은 플레이어가 만든 무명의 모험가들이다.

| 항목 | 내용 |
| --- | --- |
| 플레이 인원 | 1\~4인 협동 |
| 장르 | 실시간 PvE 액션 RPG (로그라이크 아님) |
| 월드 | 3D, 롤식 고정 쿼터뷰 |
| 성장 | 레벨 없음, 능력치·숙련도 중심 |
| 엔진 | Godot 4 |

- **자유로운 육성**: 고정 직업 없음. 빌드 정체성은 능력치 요구치와 무기 숙련도에서 자연스럽게 생긴다.
- **무기 기반 전투**: 장착한 무기가 쓸 수 있는 스킬 풀을 정한다.
- **입체적인 전략**: 높이, 점프, 등반, 공중 공격, 방어와 기술 연계.
- **성장 = 탐험 범위**: 능력치가 오르면 못 가던 높은 곳에 간다.
- **협동과 탐험**: 혼자도 가능하지만, 함께하면 전투·이동 모두 전략이 늘어난다.

캐릭터 능력치, 숙련도, 장비, 아이템은 영구히 유지된다.

## 2. 시점·조작·이동

3D 월드에 롤식 고정 쿼터뷰 카메라를 쓴다. 카메라는 회전하지 않으며, 우클릭 이동과 QWER 스킬 조작을 유지한다.

### 조작

| 입력 | 기능 |
| --- | --- |
| 우클릭 | 위치 지정 이동 (매달린 중에는 벽면 이동) |
| Space | 점프 |
| F | 짧은 돌진 |
| QWER | 배치한 스킬 |
| 좌클릭 | 조준 기술 확정, 일부 기술의 추가 행동 |
| Esc | 기술 조준 취소 |

### 점프

점프 순간의 수평 속도가 고정되며, 공중에서는 자기 입력으로 궤도를 바꿀 수 없다. 단, 외부 힘(아군 방패밀기, 적 넉백, 마법)을 받으면 궤도가 바뀐다. 몸 방향과 공격 방향은 공중에서도 바꿀 수 있다.

| 상황 | Space 결과 |
| --- | --- |
| 이동 중 | 현재 방향·속도로 점프 |
| 정지 | 제자리 수직 점프 |
| 가장자리에서 막혀 정지 | 가려던 방향으로 달리기 점프 |

- **이동 의도 보존**: 도달 불가 지점을 클릭하면 가장자리에서 멈추되 목표 방향을 기억한다. 다른 곳을 클릭하거나 일정 시간이 지나면 초기화한다.
- 2단 점프·벽점프는 해당 이동 능력을 가진 경우에만 가능하다.

### 점프 높이·거리

점프 높이는 **근력 대비 총무게**, 수평 거리는 **이속(근력 ÷ 총무게) × 체공 시간**으로 정해진다. 별도의 "긴 점프" 기술은 없다.

- 높이 = 기본 높이 × f(근력 ÷ 총무게). f는 완만한 곡선, 변동 폭은 기본값의 ±30% 안팎으로 묶는다.
- 총무게 = 종족 체중 + 장비 무게. 종족마다 체중과 시작 근력이 다르다.
- 이속이 곧 점프 거리이므로 이속 상한을 둔다 (이속 버프 하나로 거리 게이트가 뚫리지 않게).
- 턱 위에 커서를 올리면 도달 가능 여부를 표시하거나, 점프 궤적 미리보기를 제공한다.

| 무게가 늘면 (후보) | 영향 |
| --- | --- |
| 점프 높이 | 낮아짐 |
| 돌진 거리 | 짧아짐 |
| 등반 지구력 소모 | 커짐 |
| 넉백 저항 | 커짐 (무거움의 보상) |

### 돌진

- F로 짧은 거리 돌진, 공중 사용 불가, 벽과 충돌한다.
- 돌진 중 스킬을 조합한다. 각 기술이 돌진을 따로 구현하지 않고, 공통 이동 동작과 기술 동작을 동시에 실행한다.

### 벽 등반

| 벽면 방향 | 이동 |
| --- | --- |
| 앞면 (카메라를 향함) | 상하좌우 자유 |
| 뒷면 | 상하좌우 자유 (벽 투명화) |
| 옆면 | 수직 이동만 |

- 매달린 상태에서는 클릭 레이를 **현재 붙어 있는 벽면에만** 쏜다.
- 옆면은 쿼터뷰에서 "벽을 따라 안쪽으로"와 "위로"가 화면상 같은 방향이라 수직만 허용한다.
- 등반 성능은 근력·지구력에 따라 달라지고, 매달린 중에는 한손 공격·약화형 기술만 쓴다.

### 가림 처리

- 카메라와 캐릭터 사이를 가리는 벽은 투명(디더링) 처리한다.
- 투명 상태인 벽은 클릭 레이 판정에서 제외한다.

## 3. 무기·스킬 시스템

장착한 무기들의 스킬을 합친 **스킬 풀**에서 플레이어가 QWER에 직접 배치한다. 조합마다 스킬 세트를 따로 설계하지 않아 무기가 늘어도 설계량은 무기 수에 비례한다.

### 장착 규칙

| 항목 | 규칙 |
| --- | --- |
| 한손 무기 | 두 손에 자유 조합 (검, 창, 방패) |
| 양손 무기 | 두 손 모두 차지 (활, 스태프, 추후 대검) |
| 스킬 풀 | 장착 무기 스킬의 합 |
| 같은 무기 2개 | 전용 조합 스킬이 풀에 추가 (예: 쌍검) |
| 방패 | 스킬 1개 (방어 + 방패밀기 내장) |
| 양손 무기 스킬 수 | 5\~6개 (고를 여지 확보) |
| 배치 | 조합별 마지막 배치 기억, 첫 사용 시 자동 배치 |

### 쌍검과 무기 계열

- **쌍검**: 검 스킬 + 쌍검 전용 스킬을 추가하는 방식. 전용 스킬은 새로 설계한다.
- **계열 공용 스킬**: 검·쌍검·대검은 검 계열로 묶고 검기 같은 기술을 공유한다. 대검판 검기는 같은 스킬에 위력·충전 속도만 다르다.
- 계열 공용 스킬의 숙련도는 계열 안 모든 무기에 반영된다.

### 요구 능력치

- 무기마다 요구 능력치가 다르며 **소프트락**이다. 미달이어도 장착은 되지만 피해량·공속이 감소한다.
- 요구치 때문에 대부분 한 무기 계열로 굳어지고, 능력치를 고르게 올린 플레이어만 여러 무기를 오간다.
- 고급 무기 요구치는 로그 곡선에서 "몇 시간 수련하면 닿는지" 기준으로 역산한다.

### 무기 교체

- 전투 중 교체 불가.
- 예외는 클래스가 아닌 **해금 요소**로 준다. 여러 능력치를 고르게 올렸을 때 열리는 웨폰마스터 패시브, 또는 히든 장비.

### 밸런스 원칙

스킬이 세트가 아니라 개별로 비교되므로, 같은 풀 안에서 스킬 역할(단일 딜, 광역, 이동, 방어)이 겹치지 않게 나눈다.

## 4. 검+방패 전투

가장 구체적으로 설계된 조합이며, 아래 배치는 검+방패의 **기본 자동 배치**다. 플레이어는 스킬 풀 안에서 바꿀 수 있다.

| 기본 슬롯 | 기술 | 소속 | 핵심 |
| --- | --- | --- | --- |
| Q | 찌르기 | 검 | 단일 대상 근접, 지상 전용 |
| W | 횡베기 | 검 | 부채꼴, 지상·공중 가능 |
| E 유지 | 방패 들기 | 방패 | 유지형 방어 |
| E 유지 + 좌클릭 | 방패밀기 | 방패 | 지상 전용, 약한 피해 + 넉백 |
| R 유지 후 해제 | 검기 | 검 계열 공용 | 충전 시간에 따라 피해량·사거리 증가 |

### 돌진 연계

- F → Q: 돌진 찌르기
- F → W: 돌진 횡베기
- F → E: 방패 들고 돌진
- F → E 유지 + 좌클릭: 돌진 중 방패밀기

### 방패 방어

- 공중에서 방패 들기는 가능, 방패밀기는 불가.
- 받아내는 타이밍과 능력치에 따라 완벽 방어 / 밀려남 / 방어 실패로 나뉜다.

### 검기

손톱처럼 휘어진 분출형 투사체. 피해량·사거리는 충전 시간에 대해 로그 함수로 증가한다.

| 숙련도 단계 | 최소 충전 시간 |
| --- | --- |
| 1 | 2초 |
| 2 | 1초 |
| 3 | 0.5초 |
| 4 | 0초 |

- 최대 충전 5초, 최소 충전 미달 시 발사 안 됨, 발사 후 약 0.3초 후딜.
- 숙련도가 높을수록 최대 피해량·사거리·충돌 위력 증가.
- 다른 분출형 공격과 충돌하면 위력에 따라 관통 / 상쇄 / 소멸.
- 충전 중 이동 가능 여부, 공중 시전 가능 여부는 미정.

## 5. 전투 판정

3D 전환으로 실제 3D 히트박스로 판정하며, v0.1의 높이 보정 규칙은 대부분 불필요해졌다.

- 공격별 히트박스로 수평 위치와 높이를 함께 판정한다.
- 지상에서 모든 공중 적을 공격할 수는 없다. 횡베기 등은 실제 공격 높이가 중요하다.
- 체감상 억울한 빗나감을 줄이려면 히트박스를 시각 모델보다 약간 크게 잡는다.
- 쿼터뷰에서 높이를 읽기 쉽도록 공중 개체에는 바닥 그림자를 표시한다.
- 판정 권한(누가 명중·방어를 결정하는지)은 9장 네트워크를 따른다.

## 6. 성장 시스템

캐릭터 레벨 없이 능력치(기본 체급)와 **무기 숙련도(빌드 정체성)** 두 층으로 성장한다. 성장의 목적은 더 높은 곳, 더 어려운 지역에 가는 것이며, 진행도가 크게 다른 플레이어끼리 함께 노는 것은 우선순위가 아니다.

| 층 | 성장 방식 | 역할 |
| --- | --- | --- |
| 능력치 | 행동·수련, 로그 곡선 (필요 경험치는 지수 증가) | 무기 사용 성능, 이동 능력(게이트 통과) |
| 무기 숙련도 | 행동당 고정 경험치, 단계형 효과 | 빌드 정체성, 기술 강화·해금 |
| 임계점 특전 | 능력치가 특정 값을 넘으면 고유 패시브 | 특화 빌드 보상 |

### 능력치

- 근력, 민첩, 지능, 지구력 (공식 미정). 반응속도는 민첩에 통합해 별도 능력치로 두지 않는다. 민첩은 스킬 선후딜 감소(상한 20\~30%), 방향 전환 속도, 완벽 방어·회피 판정 시간창, 벽점프를 맡는다. 이속은 근력 ÷ 총무게로 정한다.
- 로그 곡선이라 낮은 능력치는 빨리 오르고 높은 능력치는 느리다. 무기를 갈아탈 때의 비용이 낮고, 장기적으로는 능력치가 수렴한다.
- 수렴으로 빌드가 비슷해지는 문제는 숙련도와 임계점 특전이 정체성을 맡아 해결한다.

### 숙련도

- 경험치는 **행동을 수행할 때마다 고정량**. 적의 강함으로 보너스를 주지 않는다 (버스 방지).
- 효과는 **단계형**이며 단계마다 수치 증가와 기술 변화를 함께 준다 (예: 검기 단계별 최소 충전 단축).
- 단계 간격은 점점 넓어지며, 최종 단계 직전 구간을 길게 둔다.

### 경험치 보정

비교 기준은 **해당 숙련도 단계 vs 몬스터 등급**이다. 몬스터 등급은 숙련도 단계와 같은 눈금을 쓴다.

| 상대 | 획득 숙련도 |
| --- | --- |
| 같거나 강한 적 | 최대치 |
| 한 단계 아래 | 최대치 (완충 구간) |
| 그보다 약한 적 | 감소, 일정 이하면 0 |
| 수련장 | 최대치보다 낮게 고정 |

- 방어형 행동은 공격한 적의 등급과 방패 숙련도 단계를 비교한다.
- 새 무기를 들면 그 무기 단계 기준으로 계산되어 약한 적에게서도 경험치를 제대로 받는다.

### 상한

- 숙련도에는 상한이 있다. 상한 = 현재 최종 지역을 깰 수 있는 수준.
- 업데이트마다 새 지역과 함께 상한을 확장한다.

### 종족

종족별 초기 능력치와 패시브가 다르고 기본 성장 효율은 같다. 일부 종족 패시브는 숙련도 성장 보너스를 줄 수 있다 (8장).

## 7. 탐험과 물리적 게이트

지역 진입은 숫자 요구치(아케인포스류)가 아니라 **지형으로** 막는다. 게이트는 높이·거리 같은 물리 단위로 정의하고, 각 빌드는 능력치를 도달 가능 높이·거리로 바꾸는 공식을 가진다.

| 능력치 | 이동 수단 | 강점 | 약점 |
| --- | --- | --- | --- |
| 근력·지구력 | 등반, 높고 먼 점프 | 높이 제한이 적음 | 느림, 지구력 소모, 매끈한 벽 불가 |
| 민첩 | 벽점프 | 근력 없이 좁은 수직 통로 돌파 | 마주 보는 벽이 있어야 함 |
| 지능 | 블링크, 마법 발판 | 즉발 | 마나·쿨타임, 시야가 닿는 곳까지만 |

- 레벨 디자인은 지형만 만들고, 통과 여부는 공식이 판정한다.
- 한 수단이 모든 게이트를 무시하지 않도록 수단별 약점을 지형으로 활용한다.
- 일부 게이트는 의도적으로 한 빌드 전용으로 두고 히든 아이템 보상과 연결한다.

### 협동 이동

- 근력캐가 올라가 밧줄을 내려주기, 법사가 마법 발판으로 파티 태우기, 민첩캐가 먼저 건너가 레버 당기기.
- 혼자는 못 가지만 같이 가면 가는 곳을 만든다.
- 저진행도 플레이어가 협동으로 높은 지역에 따라오는 것은 허용한다. 몬스터 강도와 소프트락 때문에 할 수 있는 게 없고, 숙련도 경험치는 행동당 고정이라 버스가 성립하지 않는다.

### 아군 상호작용

밀기·넉백은 아군에게도 **항상** 적용된다. 공중의 아군을 밀면 도약이 되고, 이것이 팀워크 연계의 기본 수단이다 (예: 점프한 팀원에게 방패밀기 → 멀리 도약).

| 대상 | 효과 |
| --- | --- |
| 공중의 아군 (점프 도약) | 궤도 변경, 피해 없음 |
| 지상의 아군 | 적과 동일 (넉백·피해·경직) |

- 도약 힘 = 미는 사람 근력 ÷ 날아가는 사람 총무게.
- 낙사 피해 있음 (추후 패치로 조정).
- 네트워크: 미는 쪽 클라가 명중을 판정하고, 맞은 쪽 클라에 힘 이벤트를 보내 적용한다. 핑 차이를 감안해 아군 대상 판정 범위를 넉넉하게 잡는다.
- 아군 피해·경직·낙사 여부는 모두 데이터 플래그로 두어 패치 때 수치만 바꾼다.

### 난이도

지역의 난이도는 몬스터 강도로 자연스럽게 생긴다. 보스는 같은 보스에 수치만 바꾼 난이도 단계를 두어 콘텐츠 볼륨을 싸게 늘린다.

## 8. 종족·아이템·경제

종족과 아이템 획득 경로는 v0.1 방향을 유지하고, 장비 강화와 장비 귀속은 보류한다.

### 종족 (후보, 수치 미정)

| 종족 | 체중 | 특징 |
| --- | --- | --- |
| 인간 | 보통 | 균형 잡힌 초기 능력치, 숙련도 성장 패시브 후보 |
| 엘프 | 가벼움 | 민첩·지능 유리, 점프 높이 유리 |
| 드워프 | 무거움 | 근력·지구력 중심, 넉백 저항 유리 |
| 오크 | 무거움 | 높은 시작 근력, 도끼·몽둥이 위주로 무기 제한. 히든 오크 석궁으로 해제 |

### 아이템 획득 경로

| 종류 | 역할 |
| --- | --- |
| 마을 상점 전용 | 일반 장비, 소모품, 특수 기능 아이템 (드랍의 하위 호환이 되지 않게) |
| 몬스터 드랍 | 전투 장비, 재료, 희귀 아이템 |

| 제작·강화 | 재료로 장비 개선 (방식 보류) |

- 조합 조건부 효과 아이템 유지 (예: 양손에 검을 들었을 때만 공속 증가).

### 보류 사항

- **장비 강화 방식**: 확률형 / 결정형 / 옵션 파밍 중 미정.
- **장비 넘겨주기**: 허용 또는 고등급 귀속. 아이템 시스템을 정할 때 함께 결정.

## 9. 네트워크·기술 구조·BM

비공개 알파로 시작해 얼리액세스 패키지 + 무료 업데이트로 가고, 라이브 서비스로 전환할 때 서버를 통합한다. 캐릭터는 처음부터 서버에 저장한다. 친구 그룹 단계에서는 PvE 협동이라 **"느끼는 사람이 판정한다"** 원칙으로 클라 예측과 서버 보정을 뺀다.

### BM과 운영

| 항목 | 결정 |
| --- | --- |
| BM | 얼리액세스 패키지 + 무료 대형 업데이트 |
| 캐릭터 저장 | **서버 저장** (항상 온라인, 오프라인 플레이 불가). 이주·통합 때 검증된 캐릭터만 넘어감 |
| 세계 저장 | 그룹 단위 세계 (저장 위치는 미정) |
| 거래 | 없음 (같은 세션 안 드랍 나눠 갖기만) |
| 업데이트 | 새 지역 + 숙련도 상한 확장 |
| 회차 | 2회차 모드 없음. 모두가 같은 이야기를 함께 진행하는 것을 지향 |

### 출시 로드맵

| 단계 | 형태 | 세계관 |
| --- | --- | --- |
| 비공개 알파 | 선택된 사람들만 하나의 영구 세계에 ("너네 한배 탄 거야") | 한배 탄 첫 도시 |
| 얼리액세스 | 친구 그룹(1\~4인)마다 따로 세계 | 수많은 도시가 각자 다른 시간선을 떠돎 |
| 라이브 서비스 | 하나의 공용 세계로 **서버 통합** | 모든 도시가 하나의 대륙으로 수렴 |

- 비공개 알파는 플레이 테스트 역할도 겸한다 (콘텐츠 소비 속도, 밸런스, 협동 재미 검증). 수십 명 규모면 전용 서버 1개가 필요하고, 4인용 보스 구역은 파티 단위 입장으로 나눈다.
- 서버 통합 시 세계 자체는 합치지 않는다. 공용 세계를 새로 만들고, 서버에 저장된 캐릭터만 이주한다. 기존 세계는 기념으로 남긴다.
- 서버 통합은 운영 이벤트이자 세계관 최대 사건으로 연출한다.

### 네트워크 구조

- 리슨 서버 (플레이어 한 명이 호스트), 1\~4인. 그룹이 세계를 상시 켜둘 수 있게 전용 서버 파일도 배포한다 (운영은 플레이어 몫).
- 스팀 출시 기준 GodotSteam + 스팀 릴레이로 NAT 문제를 피한다.

| 판정 | 권한 |
| --- | --- |
| 내 캐릭터 이동·점프·등반 | 내 클라 |
| 내 공격의 명중 | 내 클라 |
| 내 방어·회피 성공 (완벽 방어 포함) | 내 클라 |
| 몬스터 AI·HP·사망 | 호스트 |
| 드랍·보상 | 호스트 |
| 검기끼리 충돌 | 호스트 |

- 원격 캐릭터는 보간으로 표시한다.

### 라이브 서비스 전환 대비

- 명중·드랍·저장은 모두 **판정 함수**를 거치게 해서, 나중에 서버 쪽으로 갈아끼울 수 있게 한다 (Godot 헤드리스 서버). 모르는 사람이 섞이는 공개·공용 서버로 가는 시점에 클라 판정을 서버 판정으로 옮긴다 (치팅 방지).
- 콘텐츠는 데이터로 분리한다.
- 세계 데이터와 캐릭터 데이터를 분리해 저장한다. 캐릭터는 서버에 둔다.

### 데이터 구조

- 캐릭터·무기·스킬·계열·종족·아이템·지역 데이터를 분리한다.
- 스킬은 개별 무기 또는 무기 계열에 소속되고, 무기는 "계열 + 고유 스킬 목록"을 가진다. 같은 무기 2개 장착 시 조합 스킬을 풀에 추가한다.
- 무기·지역·벽마다 요구 능력치(또는 높이·거리) 필드를 둔다.
- 숙련도 단계 기준값과 몬스터 등급은 테이블로 뺀다.
- 소프트락 패널티는 함수 하나로 통일한다.

## 10. 핵심 루프·월드·스토리

목표는 최대한 자유로운 성장이다. 메인퀘가 방향을 주고, 물리적 게이트와 대형 서브퀘가 자유를 준다. 퀘스트 대신 "보이는데 못 가는 곳"이 성장 동기를 만든다.

### 루프

| 주기 | 루프 |
| --- | --- |
| 초 | 고른 무기로 전투 → 숙련도 |
| 분 | 탐험 → 게이트·히든 아이템·재료 발견 |
| 시간 | 마을 귀환 → 수련·제작·장비 교체 → 막혔던 게이트 재도전 |
| 업데이트 | 새 지역 + 숙련도 상한 확장 |

### 월드 구조

시작 도시 안의 근원이 힘을 키울수록 더 넓은 반경을 끌고 다른 시대·장소로 이동한다. 이동할 때마다 끌려온 땅과 도착한 곳이 합쳐져 대륙이 점점 만들어지고, 반경 밖의 지역은 뒤에 남겨진다. 새 지역은 메인 진행(도시의 이동)으로 열리고, 이미 붙은 지역 안에서는 자유롭게 다닌다. 대륙에는 퍼즐 조각이 빠진 듯한 빈자리가 생기며, 메인 챕터 진행에 따라 그 자리에 새 조각이 들어와 이웃 구역의 상태를 바꾼다. 구역 하나 = Godot 씬 하나로, 경계에서 씬 단위로 로딩한다.

- 높이·거리·마법 게이트를 섞어 빌드마다 먼저 열리는 지역이 다르게 한다.
- 어떤 빌드도 혼자 모든 게이트를 열 수 없게 한다 (다른 빌드 육성·협동 동기).
- 본 적 있는데 못 간 곳은 지도에 자동 표시하고, 마을 NPC 소문으로 힌트를 준다.

### 세계관 전제

세계의 시간선이 뒤섞이며, **같은 장소의 다른 시대**가 공간 단위로 잘려 붙는다. 사막이 끝나기도 전에 설산이 나타나고, 경계에는 잘린 산 단면이 그대로 드러난다.

- 배경은 클래식 서양 판타지. 허브는 일부가 잘려나간 중세 도시다.
- 지역만이 아니라 괴수와 물체도 단독으로 옮겨온다. 옮겨온 생명체는 도착한 환경에 맞게 변이한다 (예: 사막으로 옮겨와 모래를 헤엄치는 크라켄·상어). 같은 괴수 모델을 환경별 변종으로 재활용할 수 있다. 지역마다 거대 괴수는 한 마리, 나머지는 일반 몬스터로 채운다.
- 조각은 한 번 붙으면 고정된다. 실시간 교체는 보스전 등 연출 구간에서만 스크립트로 쓴다.
- 조각 경계는 단차·잘린 절벽이 되어 물리적 게이트와 등반 벽 역할을 한다. 경계면에는 일관된 시각 효과(일렁임, 멈춘 먼지 등)를 써서 버그가 아닌 연출로 보이게 한다.
- 각 조각은 그 땅의 역사를 보여주는 환경 서사가 된다.
- 현상의 고유 명칭은 미정 ("인커젼"은 다른 게임의 용어와 겹쳐 피한다).

### 이웃 변형 규칙

조각은 붙는 순간 경계 너머로 영향을 쏟아내고, 그 결과로 이웃 구역이 바뀐 채 고정된다. 같은 에셋으로 전혀 다른 구역을 만드는 수단이다.

| 붙은 조각 | 이웃에 생긴 변화 |
| --- | --- |
| 수위가 높은 바다 시대 | 기존 도시가 **수몰 도시**가 됨 |
| 사막 시대 | 숲이 모래에 반쯤 파묻힌 폐허가 됨 |
| 빙하기 | 마을이 얼어붙은 채 멈춤 |

- **수몰 도시**: 최고 마법사가 만든 공기돔 안의 도시. 돔 안은 일반 지상 구역과 같아서 수영·수중 전투 시스템이 필요 없다. 돔 밖은 물로 보이는 배경이자 통과 불가 경계다.
- 공기돔 같은 편의 설정은 이야기 거리로 쓴다 (돔을 누가 유지하는지, 돔이 흔들리면 어떻게 되는지 → 대형 서브퀘·보스전 소재).

### 근원과 이동하는 도시

근원은 처음부터 시작 도시 안에 있었다. 도시는 끝까지 함께 이동하는 유일한 장소이므로 메트로배니아의 중심이 되고, 결말은 출발점으로 돌아오는 원형 구조다.

| 위치 | 게이트 성격 |
| --- | --- |
| 시작 도시 | 장기 (게임 전체에 걸쳐 조금씩 열림) |
| 도시 근처, 이동 반경 안 | 중기 (몇 지역 뒤에 열림) |
| 반경 밖, 남겨질 지역 | 단기 (그 지역에 있는 동안 해결) |

- 도시의 난이도는 메인 진행에 맞춰 함께 오른다 (도시에도 괴수가 옮겨온다). 단, 도시 안 **대피소**는 항상 안전한 거점이다. 사건 당시 마침 도시에 있던 강한 장군과 용병들이 지키고 있으며, 이후 이들 사이의 분열을 이야기 소재로 쓸 수 있다. 무기 수련을 맡는 사부들(오프닝의 훈련 교관)은 분열과 무관한 중립이자 주인공 편이라, 어느 쪽 편을 들어도 수련은 막히지 않는다.
- 남겨진 지역에서 놓친 콘텐츠는 이스터에그·로어·외형 아이템으로 한정한다 (성장 요소는 놓칠 수 없게). 다시 볼 방법은 미정 (2회차는 쓰지 않음, 후보: 남겨진 지역이 나중에 조각으로 다시 돌아옴).
- 도시는 이야기상 반경 약 2km 대도시지만, 실제로 걷는 곳은 성벽 안 몇 개 구역이고 나머지는 원경으로 처리한다.

### 1막 1장: 오프닝

1. 주인공은 모험가가 되려고 대도시에 훈련받으러 온 훈련생이다. 협동 플레이의 친구들은 함께 훈련받던 동기들이다.
2. 훈련(튜토리얼)을 마치는 순간 땅이 울리고, 도시 반경 약 2km를 빼고 전부 사라진다.
3. 정신을 차리면 도시가 사막 한가운데로 옮겨져 있다.
4. 사막에서 전갈 등 괴수 무리가 몰려온다. 가끔 모래 속을 헤엄치는 상어가 보인다 (사막 거대 괴수 떡밥).
5. 1차 목표: 몰려온 괴수를 물리치고 사막으로 나아간다.
6. 이후 도시는 사막 일부까지 끌고 다음 장소로 이동한다.

### 메인퀘

지역 순서를 정해주는 추천 경로다. 이미 붙은 지역 안에서는 자유롭게 다니며, 메인퀘를 하지 않아도 성장과 탐험은 진행된다. 단, 새 지역은 도시가 이동해야 열린다.

- 메인 목적지에는 어떤 빌드든 통과할 수 있는 진입로를 최소 하나 둔다. 빌드 전용 게이트는 서브퀘·히든 지역·보물에만 쓴다.
- **시퀀스 브레이크**: 먼저 도착한 지역은 탐험·전투·서브퀘가 모두 되지만, 메인 이벤트는 퀘스트가 도달할 때까지 잠든다. 사건이 아직 일어나지 않은 상태로 본다.
- 메인퀘 보상은 스토리와 편의(지름길, 거점 해금) 위주. 핵심 성장은 탐험·수련·서브퀘에서 나온다.
- 지역 난이도는 메인 순서대로 오른다. 건너뛰면 더 어려운 것이 유일한 브레이크다.

### 서브퀘

개수는 적고 하나하나가 큰 이야기다. 지역당 2\~3개.

| 역할 | 예시 |
| --- | --- |
| 빌드 전용 콘텐츠 | 법사만 갈 수 있는 공중 유적의 이야기 |
| 시스템 해금 | 웨폰마스터 해금, 오크 석궁 획득 |
| 세계관 깊이 | 메인퀘에서 스쳐 간 세력의 뒷이야기 |
| 협동 유도 | 혼자는 못 여는 게이트 너머의 이야기 |

- 메인 스토리를 참조하는 대사는 진행 플래그에 따라 바뀐다.

### 히든 콘텐츠

공략을 봐도 한 사람에게만 적용되는 진짜 히든이다. 클라이언트 파일에 있으면 데이터마이닝으로 털리므로, **조건과 내용은 서버에만 두고 발동한 사람에게만 내려준다** (캐릭터 서버 저장이 전제).

| 방식 | 내용 | 쓰임 |
| --- | --- | --- |
| 행동 이력 | 플레이어가 살아온 방식으로 발현 (예: 완벽 방어 수천 번, 무사망 통과) | 조건의 뼈대 |
| 캐릭터별 조건 | 같은 히든이라도 위치·순서·세부 조건이 캐릭터마다 무작위 | 공략은 "이런 게 있다"까지만 |
| 세계 최초 1회 | 전 세계에서 처음 달성한 한 명만 획득 | 상징적인 것에만 |

| 보상 | 받는 방식 | 강도 |
| --- | --- | --- |
| 특수 스킬 | 행동 이력 + 캐릭터별 조건 | 일반 스킬과 비슷, 플레이 방식이 독특 (예: 방패 던지고 돌려받기, 벽에 튕기는 검기, 공중 아군 런치 1회 추가) |
| 각성·계승 | 행동 이력 기반 | 무기·칭호에 고유 스킬 묶음이 붙어 스킬 풀 확장 ("전직" 대신, 고정 직업 없음 원칙 유지) |
| 유일 아이템 | 세계 최초 1회 | 세상에 하나뿐인 고유 효과, 최강은 아님 |

- 히든 스킬도 QWER 4칸 중 하나를 차지한다. 스킬 슬롯이 자연스러운 상한이다.
- "더 센 것"이 아니라 "다른 것"을 준다. 협동에서 한 명이 다 해먹는 구조를 막기 위함이다.

### 협동 진행

진행도는 **캐릭터가 아니라 세계 기준**이다. 세계는 친구 그룹 소유이고, 그 세계의 보스와 스토리 상태는 하나뿐이다.

| 대상 | 저장 단위 |
| --- | --- |
| 메인퀘·보스·지역 이벤트 | 세계 (접속한 전원이 함께 경험) |
| 서브퀘 완료 | 세계 (참여자에게 보상) |
| 능력치·숙련도·장비 | 캐릭터 (서버 저장, 다른 세계로 들고 갈 수 있음) |

- 늦게 합류한 친구는 그룹 진행도에 합류한다. 지나간 스토리를 보려면 자기 세계를 새로 시작한다.

### 업데이트 단위

새 지역 = 메인 챕터 1개 + 대형 서브퀘 2\~3개 + 숙련도 상한 확장. 여러 지역이 모여 **막**이 되고, 막이 바뀌는 순간은 퍼즐 빈자리에 새 조각이 들어오는 세계 사건으로 연출한다.

| 막 | 범위 | 시작 사건 |
| --- | --- | --- |
| 1막 (얼리액세스 첫 출시) | 지역 5개 + 마른 도시 | 오프닝: 시작 도시가 사막으로 이동 |
| 2막 (첫 대형 업데이트) | 수몰 도시부터 | 빈자리에 바다 조각이 들어와 낮은 도시가 잠김 |

### 구역 기획: 수몰 도시 (메인 챕터)

2막의 시작. 5번째 지역을 깨면, 처음부터 비어 있던 퍼즐 자리에 수위 높은 바다 시대 조각이 들어온다. 유난히 낮았던 도시가 그대로 잠기고, 최고 마법사가 공기돔을 쳐서 도시를 붙잡는다. 돔 밖에는 크라켄이 산다. 같은 도시를 잠기기 전(마른 도시)과 후(수몰 도시) 두 버전으로 만든다.

- **악역**: 최고 마법사. 도시를 지배하고 주민을 세뇌한다. 진짜 동기는 소유욕 ("바다가 가져가게 둘 수 없어. 전부 내 거야.")
- **핑계**: 슬픈 기억을 치유하려 했다는 사연. 처음엔 그럴듯하게 믿게 하고, 이후 돔 곳곳의 기록(세뇌 명령서, 탈출하려던 주민을 처리한 흔적 등)으로 무너뜨린다.
- **흐름**: 원정대가 마법사를 처치 → 돔이 흔들림 → 마법석을 발동해 도시를 살리려 준비 → 핑계가 무너지는 진실 발견.
- **클라이맥스**: 마법석 발동과 크라켄 보스전을 합친다. 촉수가 돔을 뚫고 들어오고, 한 명이 발동하는 동안 나머지가 방어한다 (솔로는 발동 자동 진행).
- 세뇌가 풀린 뒤 주민 반응은 대사 플래그 교체로 처리한다.

## 11. 개발 순서

첫 완성품은 **무기를 바꿔 끼며 전투 스타일을 바꾸는 3D 네트워크 전투 실험실**이다. 2단계부터 매 단계 2인 동기화 테스트를 같이 한다.

- [ ] **1. 테스트 방**: 3D 사각형 방, 높이 차 지형, 등반 벽(앞·옆면), 허수아비, 무기 선택대
- [ ] **2. 기본 캐릭터**: 우클릭 이동, 점프 규칙 3종, F 돌진, 고정 쿼터뷰 카메라, 벽 투명화
- [ ] **3. 장비·스킬 풀**: 한손·양손 규칙, 장착 무기 스킬 합산, 계열 데이터 구조
- [ ] **4. 스킬 배치**: QWER 배치 UI, 조합별 배치 기억, 조준 인디케이터
- [ ] **5. 검+방패**: 찌르기, 횡베기, 방패 방어·밀기, 검기, 돌진 연계
- [ ] **6. 등반·게이트**: 벽면 이동, 능력치 → 도달 높이·거리 공식, 게이트 1\~2개
- [ ] **7. 무기 확장**: 쌍검(전용 스킬), 창, 활, 스태프
- [ ] **8. 몬스터·전투**: 늑대 등 적 AI, 피해, 방어, 몬스터 등급
- [ ] **9. 작은 RPG 루프**: 숙련도·경험치 보정, 저장(프로토타입은 로컬, 이후 캐릭터 서버 저장으로 이전), 간단한 상점과 수련장

## 12. 미결 사항

루프와 월드 구조의 큰 틀은 10장에서 정했다. 남은 것은 세계관·스토리 내용과 수치 튜닝이다.

- [ ] 시간선 뒤섞임의 원인과 반전, 원정대의 정체, 현상의 고유 명칭, 1막 지역 5개의 시대·괴수 구성
- [ ] 능력치 종류와 로그 공식, 이동 수단별 도달 높이·거리 공식
- [ ] 숙련도 단계 수와 단계별 보상, 임계점 특전 목록
- [ ] 무기별 스킬 풀 (창, 활, 스태프, 쌍검 전용, 대검)
- [ ] 검기 피해량·사거리·충돌 위력 공식, 충전 중 이동·공중 시전 여부
- [ ] 종족 종류와 고유 패시브
- [ ] 장비 강화 방식, 장비 넘겨주기 허용 여부
- [ ] 사망 페널티와 부활 방식
- [ ] 솔로·협동 난이도 조정
- [ ] 웨폰마스터 해금 조건
- [ ] 비공개 알파의 성격 (정식 출시 전 단계인지, 정식 출시를 대체하는지), 참가자 규모·선정 방식
- [ ] "모두가 함께 진행"을 얼리액세스 단계에서도 낼지 (후보: 전 세계 진행도를 합산해 다음 막을 여는 공동 진행)
- [ ] 세계 데이터 저장 위치 (호스트 로컬 / 서버)
- [ ] 놓친 이스터에그를 다시 보는 방법
- [ ] 히든 콘텐츠 목록과 조건 설계
- [ ] 반복 콘텐츠 (후보: 괴수 무리가 도시·지역에 갑자기 옮겨오는 전이 이벤트, 협동 방어)
