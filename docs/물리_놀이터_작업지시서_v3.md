## 0. 작업 규칙

1. **단계 순서대로.** 완료 조건을 전부 확인하기 전에는 다음 단계로 넘어가지 않는다.
2. **단계가 끝나면 멈추고 보고한다** (맨 아래 형식). 사용자가 "다음"이라고 하면 진행.
3. **범위 밖 기능을 만들지 않는다.**
4. **문서에 없는 결정이 필요하면 멈추고 묻는다.** "기본값"으로 적힌 수치·공식은 그대로 쓴다.
5. **이미 있는 기능은 갈아엎지 말고 고친다.** 구조를 크게 바꿔야 하면 이유를 보고하고 묻는다.
6. 정적 타입 GDScript. **물리 상태 변경은 `_physics_process`에서만** 한다. 입력·RPC 콜백은 요청을 큐에 넣기만 한다 (조사에서 밀치기·돌진·잡기·힘 수신이 콜백에서 바로 속도를 바꾸는 것이 확인됨).
7. 각 단계 끝에 git 커밋.
8. 문서(`docs/`)는 사용자가 관리한다. 고치지 않는다.

### CLAUDE.md 절대 규칙 (프로젝트 CLAUDE.md에 그대로 넣는다)

- 클라이언트는 자기 이동·점프·돌진만 정하고(서버가 속도·거리 검사), 명중·밀기·잡기·피해·최초 획득·보상 등 나머지 판정은 서버가 한다.
- 최초 판정은 DB 유일 제약으로만 한다. 게임 서버 if문 금지.
- 사건 로그는 추가만 한다. 수정, 삭제 금지.
- 조건과 세계 상태는 서버 DB의 데이터로 둔다. 히든 조건, 대사, 보상은 클라이언트에 넣지 않는다.
- 밀기·던지기·충돌·피격·반동은 힘 이벤트 함수 하나를 거친다. 동작 전용 예외 금지. 물체(돌)도 예외 없다.
- 안전 도시에서는 플레이어 대상 공격·밀치기·잡기를 막는다(정해진 상황 제외). 필드에서는 파티·동의로 막지 않는다. 아군 판정은 파티원 기준.
- 튜닝 값은 코드에 박지 않고 데이터와 디버그 슬라이더로 뺀다.
- 맵은 지역 조각 모듈로 만든다.
- 능력은 겹 구조, NPC 관계는 상태 칸, 시간은 서버 타이머.
- 새 기능은 만들 때마다 2인 접속으로 확인한다.
- 하지 말 것: 서버 분할, 아트 작업, 단계 완료 전 다음 단계 진행.

**알려진 버그 (단계 B에서 고친다)**
1. `Net.leave()`가 플레이 장면을 정리하지 않아 `No multiplayer peer is assigned` 오류 반복
2. 힘 수신 RPC가 `any_peer`. 플레이어 잡기가 전달받은 `by_peer`를 믿음. 돌 잡기에 거리·근력·상태 검증 부족

## 3. 판정 권한 (혼합, 확정)

| 판정 | 누가 |
| --- | --- |
| 내 이동·점프·돌진·등반 위치 | **내 클라** (서버는 검사만) |
| 이동이 말이 되는지 | **서버**. 근력 기반 상한 × 여유 + 서버가 보낸 최근 힘 |
| 밀치기·공격 명중, 아군 판별, 반동 | **서버** |
| 잡기 성립·던지기·탈출·경합 | **서버** (단일 보유 관계) |
| 피해·HP·경직·사망·리스폰·낙하 피해 | **서버** |
| 돌·허수아비 | **서버** |
| 능력치·튜닝의 판정 기준값 | **서버** (디버그 변경은 서버가 승인) |
| 무기 선택 | 서버 승인 |
| 카메라·HUD·투명화·입력 수집 | 각 클라 (로컬) |

### 힘 이벤트 흐름
1. 클라는 의도만 보낸다 ("이 방향 밀치기", "이 대상 잡기").
2. 서버가 상태·거리·쿨다운·보유 관계를 확인하고 결과를 정한다.
3. 대상이 플레이어면 서버가 **소유 클라**에 힘 이벤트를 보내고, 소유 클라가 자기 무게로 속도를 계산해 적용한다. 물체는 서버가 직접 적용한다.
4. 서버는 이벤트 ID·시각과 함께 힘 이력을 남기고, 이후 이동 검사 상한에 반영한다.

### 노드 구조 (조사 보고 제안 채택)
```
Session
├─ ServerAuthority   # 서버 피어에서만 판정. 플레이어 자식 아님
├─ World             # 정적 지형, 서버 소유 돌·허수아비
├─ Players
│  └─ PlayerBody     # 소유 클라의 이동 시뮬레이션
└─ ClientView        # 입력·카메라·HUD
```
- 호스트 입력도 참가자와 **같은 의도 검증 함수**를 거친다. 호스트 전용 우회 금지.
- 플레이어 위치 복제와 **서버 소유 HP·생존 상태 복제를 분리**한다. 플레이어 노드 전체 권한을 서버로 바꾸지 않는다.

## 4. 물리 규칙과 공식

**"이거 되나?" 해보면 진짜 된다. 동작 전용 예외는 두지 않는다.**

### 기본 공식 (기본값, 튜닝 대상)
```
total_weight = body_weight + gear_weight + held_weight        # held_weight 추가 필요
ratio        = strength / max(total_weight, 0.1)
ratio_mult(r, k) = clamp(1 + k * ln(r), ratio_mult_min, ratio_mult_max)
```

### 밀림 (버티는 힘 추가)
```
power = base_power × ratio_mult(source_strength / target_total_weight, k_push)
brace = 지상: ratio_mult(target_ratio, k_brace) / 공중·등반 중: 1.0
dv    = direction × power / brace
```
- 공중: 속도에 **더한다** (허수아비도 덮어쓰지 말고 더한다 — 조사에서 덮어쓰는 것 확인됨).
- 지상: 속도를 dv로 바꾼다. 위쪽 성분이 크면 공중으로.
- 등반 중: 벽에서 떨어진다.

### 피해·경직 (아군 = 파티원만)
| 받는 쪽 | 파티원이 보낸 힘 | 파티원 아닌 사람·적·환경 |
| --- | --- | --- |
| 공중 | 피해·경직 없음 | 피해 |
| 지상 | 넉백·피해·경직 (`ally_ground_damage/stun` 플래그) | 넉백·피해·경직 |

놀이터에는 디버그 패널에 "같은 파티" 토글을 둔다. 놀이터 맵은 전부 **필드**로 취급한다 (안전 도시 규칙은 범위 밖).

### 도약 한계
```
v_cap = sqrt(v_jump_max² + v_move_max²)      # 둘 다 근력 배율 적용 값
내 입력으로 낸 발사 속도 |v_self| ≤ v_cap
수평 h가 정해지면 수직 = min(v_jump_max, sqrt(v_cap² − h²))
```
- 제자리 점프는 높이, 돌진 점프는 멀리. 둘 다 이 식 하나로.
- **남이 준 힘은 이 상한과 무관하게 더해진다.**

### 들기 한계
```
max_lift      = strength × lift_per_strength      # 기본 2.0 → 근력 10이면 20kg
한손 잡기     = max_lift / grab_one_hand_strength_mult (2.0)
대상 무게 > 한계 → 못 든다
```

### 지구력
돌진, 등반, 들고 있기, 던지기 충전, 탈출 연타에서 소모. 지상에서 회복.

## 단계 B. 판정을 서버로 + 버그 수정 + 정리

### B-1. 구조
- 3장 노드 구조로 정리한다. ServerAuthority를 만들고 판정 코드를 모은다.
- 클라 → 서버는 **의도 RPC**만. 결과를 담은 RPC(힘·피해·잡힘 승인)는 **서버만 보낼 수 있게** 송신자 검증을 넣는다 (`any_peer` 수신 함수는 `multiplayer.get_remote_sender_id()`로 서버인지 확인).
- 3장 표대로 옮긴다: 밀치기 명중, 잡기 승인(사람 포함), 던지기, 탈출, 피해·HP·경직·사망·리스폰, 낙하 피해 확정.
- 낙하 피해: 클라가 최고점·착지를 보고하면 서버가 위치 이력으로 타당성을 확인하고 피해를 확정한다.
- 이동 검사: 서버가 동기화마다 이동 거리 ÷ 시간을 `근력 상한 × server_speed_tolerance + 최근 힘`과 비교. 이번 단계는 **경고 로그만** (되돌리지 않음).
- 물리 상태 변경을 `_physics_process`로 모은다 (0장 6번).

### B-2. 버그 수정 (2장 목록 1~4)
- 호스트 종료 시 플레이 장면·서버 소유 물체 정리.
- 힘·잡기 RPC 송신자 검증, 돌 잡기에 거리·근력(들기 한계)·상태 검증.
- DEAD 이후 다른 상태로 덮이지 않게. 사망 처리는 서버가 마지막에 한 번만.
- 디버그 패널 불일치 수정.
- 2장 5번은 원인만 밝혀서 보고 (하네스 문제면 하네스를 고친다).

### B-3. 정리
- **시간 경계 연출 제거**: 굴절 셰이더·지층 머티리얼·먼지 파티클을 뺀다. 지형(단차)은 **등반 벽으로 남긴다.** (기획: 경계는 시각 효과 없이 "좀 이상하게 붙은 느낌". 바위 잘림·갑자기 물 같은 경계 표현은 나중에 레벨 작업에서 한다. 이번엔 만들지 않는다)
- **디버그용 경계 표시**: 조각 경계 위치에 **빨간 반투명 오라 벽**(세로 면, 위로 갈수록 옅어지는 정도면 충분)을 둔다.
  - 디버그 패널 토글로 켜고 끈다. 기본값은 켜짐. 배포 빌드에서는 항상 꺼짐.
  - **보이기만 한다.** 충돌·클릭 레이·가림 처리·NavMesh에 전부 영향 없게 한다 (별도 레이어, 콜리전 없음).
  - 경계는 데이터(경계 목록)로 두고, 오라 벽은 그 목록에서 생성한다. 나중에 레벨에 경계를 추가하면 표시도 자동으로 따라오게.
- 무기 선택대는 그대로 둔다 (외형만, 전투 없음).
- 흔적만 남은 `allow_dash_jump`, `wall_jump_enabled` 플래그는 지운다 (도약 한계가 대체, 벽점프는 범위 밖).

## 단계 C-2. 점프를 "커서 지점으로" + 스마트키

단계 C의 톡/꾹(가변 점프)은 **기획에서 빠졌다.** `jump_tap_height_ratio`, `jump_hold_time`, `_apply_jump_cut()`, 떼기 처리를 걷어낸다.

### 점프 규칙
- **커서 지점으로 뛴다.** 착지점 = 커서가 가리키는 지면(높이 포함).
- **높이는 거리에 비례**한다. 가까우면 낮게, 멀면 높게.
  ```
  t = 수평거리 / 최대 사거리                 # 0~1
  정점 높이 = lerp(jump_min_hop_height, 최대 사거리일 때의 정점, t)
  착지점이 더 높으면 정점 ≥ (착지 높이 차 + jump_ledge_margin)
  ```
  이 정점과 착지점으로 발사 속도를 역산한다. **발사 속도는 도약 한계(v_cap) 안**이어야 한다.
- **한계 밖이면** 커서 방향으로 한계 거리까지 뛰고, 그 착지 지점에 **링을 표시**한다.
- **커서가 `jump_inplace_radius` 안이면 제자리 점프 = v_cap 전부 위로** (정점 = v_cap²/2g, 근력 10에서 약 2.42m. 가장 높은 점프). 반경 바로 밖은 낮은 점프라서 경계에서 높이가 확 바뀐다. 의도된 것이다. `base_jump_height`는 v_cap의 수직 성분을 정하는 값이다.
- **조준은 땅에 서 있을 때만.** 공중·돌진 중·모서리에서 떨어진 직후의 Space는 조준 없이 바로 버퍼로 간다(벽잡기, 코요테 점프, 돌진 점프). 조준 중 땅을 떠나면 조준이 사라진다.
- 공중에선 궤도를 못 바꾸는 규칙, 돌진 점프 45° 규칙(C에서 정함)은 그대로.
- 틈 가장자리 정지 후 점프: 커서가 건너편이면 그대로 커서 지점으로.

### 돌진 = 같은 예산을 전부 수평으로
- 근력÷무게로 정해지는 **도약 한계 v_cap 하나**를 세 동작이 나눠 쓴다: 전부 위 = 제자리 점프, 45° = 멀리 뛰기, **전부 수평 = 돌진**.
- (C-2 이후 변경) 돌진 속도 = `v_cap × dash_speed_mult` (**2.0**). **최대 거리 = 최대 점프 사거리(leap_max_range)**. `dash_time_max`는 쓰지 않는다. 커서가 가까우면 커서까지(최소 `dash_min_distance`). 돌진 중 점프는 발사 속도를 v_cap으로 깎는다(45° 규칙 유지).
- `dash_max_distance_base`와 고정 `dash_duration`은 지운다 (돌진 시간은 거리 ÷ 속도로 나온다). 근력 배율도 v_cap에 이미 들어 있으니 따로 곱하지 않는다.
- 서버 이동 검사의 수평 상한도 이 속도 기준으로 맞춘다.
- 실측 보고: 근력 10·20에서 돌진 속도·최대 거리·소요 시간. 지금(4m/0.18초)과 비교.

### 스마트키 (5장)
- 점프(Space)·돌진(F)에 적용. 평타는 아직 없으니 **입력 구조만 공통으로** 만들어 나중에 평타가 같은 경로를 쓰게 한다.
- 꺼짐(기본): 키 → 사거리 원 + 착지점 표시 → 좌클릭 시전 / 우클릭·Esc 취소. 표시 중에도 우클릭 이동은 막지 않는다(취소로 처리).
- 켜짐: 키 → 즉시 커서 지점으로.
- 디버그 패널과 설정 데이터에 토글.

## 단계 E. 잡기·던지기 규칙 맞추기

- **들기 한계·한손 잡기** (4장). 디버그에 "한 손에 무기 듦" 토글.
- **든 무게 합산**: 들고 있는 동안 total_weight에 더한다. 지금의 "이동 70% 고정"과 "점프·돌진·밀치기 금지"는 **빼고** 무게 공식으로 자연히 둔해지게 한다.
- **한 키 동작** (잡은 상태에서 G를 누름):
  | 누른 시간 | 결과 |
  | --- | --- |
  | `throw_hold_threshold`(1초) 전에 뗌 | 내려놓기 |
  | 1초 이상 | **포물선**: 커서 = 착지점, 충전 = 최대 사거리 |
  | Shift + 위 | **직선**: 커서 = 방향, 충전 = 세기·피해 |
  충전 중 이동 가능.
- 허수아비도 잡을 수 있게.
- **잡기 의도는 대상 ID를 담는다.** 그 대상이 이미 잡혔거나 사라졌으면 실패로 끝내고, 서버가 커서 아래 다른 대상(사람 포함)으로 바꿔 잡지 않는다.
- **돌 던지기도 힘 이벤트로** (`THROW`, 대상 = 돌, 서버가 적용). 탈출 반동도 `RECOIL` 힘 이벤트로.
- 잡은 채로 다른 행동을 막는 코드를 넣지 않는다 (나중에 다른 손 무기로 칠 수 있게).
- 공격 잡기는 **판정 함수에 "공격의 힘과 비교" 자리만** 만든다.
- 돌→플레이어 명중을 확인 가능한 배치로 테스트.
- 지구력: 들고 있기·충전·탈출 연타 비용.
