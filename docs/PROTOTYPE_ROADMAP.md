## 1. 지금 위치

**기준 코드는 `physics_playground`.** 접속·이동·점프·돌진에 더해 힘 이벤트·밀치기·잡기·던지기·등반·공중 벽잡기·낙하 피해까지 뼈대가 있다 (단계 A 조사, 2026-10-25). 판정은 아직 이전 방식(각자 클라)이라 서버로 옮겨야 하고, 세부 규칙도 기획서에 맞춰야 한다.

`PLAYTEST_01`은 다른 프로젝트(RPG 폴더) 기록이다. 그쪽의 사로·방패·횡베기는 4단계(전투 기본)에서 참고한다.

## 2. 전체 진행 순서 (기획서 v0.6)

놀이터 이후 알파까지 약 10~12주 (Claude Code 기준 추정).

| 단계 | 구현 범위 | 넘어가는 기준 |
| --- | --- | --- |
| 1. 물리 놀이터 | 1차: 접속·이동 → 점프 → 돌진 (구현됨) → *(2번 먼저)* → 밀치기·힘 이벤트 → 잡기·던지기 / 2차: 등반 → 낙하 피해 | "설계하지 않은 무브가 몇 번 나왔나" |
| 2. 네트워크 검증 (하루~이틀) | 현재 판정 구조 조사 → 혼합 판정으로 전환. 클라 2개, 이동·점프·충돌·밀기 동기화, 지연 100~200ms, 끊겼다 재접속 | 지연 200ms에서 크게 안 깨짐, 재접속 정상 |
| 3. 저장·사건 로그 (1~2주) | Supabase 계정·캐릭터 저장·재접속 보존, 모든 행동 기록 (추가만) | 재접속해도 상태 보존, 로그 누락 없음 |
| 4. 전투 기본 (2주) | 검·방패·맨손 평타, 몬스터 AI, 드랍, 숙련, 보스 1, 난이도 다른 지역 2개 | 최초 토벌·최초 도달이 연대기에 남는다 |
| 5. 세계 규칙 (1~2주) | 최초 획득(DB 유일 제약), 세계 플래그 + GM 수정, 조건 엔진, 연대기 | |
| 6. 개인화 히든 (1~2주) | 플레이어 프로필 계산, 같은 장소에서 사람마다 다른 히든 | 두 사람이 다르게 플레이한 뒤 같은 동굴에서 각자 다른 것을 발견한다 |
| 7. NPC 사회 (2~3주) | 마을, 말풍선·귓속말, ??? 이름·지식, NPC 태도 | |
| 8. 알파 콘텐츠 → 알파 | | |

**실제 진행 순서는 1(1차 앞부분, 완료) → 2 → 1(나머지) → 3 → …** 이다. 1·2의 상세 지시는 `물리_놀이터_작업지시서_v3.md`의 단계 B~G를 따른다 (v1·v2는 쓰지 않는다).

| 작업지시서 단계 | 로드맵 위치 |
| --- | --- |
| A. 현재 구현·판정 조사 (완료, 2026-10-25) | 2 |
| B. 판정을 서버로 + 버그 수정 + 시간 경계 연출 제거 + 네트워크 검증 | 2 |
| C. 조작 맞추기 (톡/꾹 점프, 돌진 거리, 도약 한계, 틈 가장자리) | 1 |
| D. 힘 이벤트·밀치기 규칙 맞추기 + 발판 | 1 (1차) |
| E. 잡기·던지기 규칙 맞추기 | 1 (1차) |
| F. 등반 규칙 맞추기 (표시된 면, 옆면 수직) | 1 (2차) |
| G. 낙하·사망 마무리 | 1 (2차) |

## 3. 알파 이후로 미룬 것

에프렌 본편, 와일드 오크족, 마녀, 소용돌이 유적, 전직 트리, 활·스태프, 국가·전쟁·항해, 로아풍 아트, 여러 마을 간 소문 전파, 생활(결혼·가족·집)과 경제, 히든 그래픽 다운로드.

## 4. 테스트 결과에 따른 판단

- 지연 200ms에서 이동이 답답하면: 콘텐츠 추가 전에 보간·검사 여유를 고친다.
- 서버 판정 이전 후 완벽 방어·흘리기가 억울하면: 판정 시간창을 넓히고, 그래도 안 되면 적 공격 예고 동작을 키운다.
- 밀치기·던지기 협동이 우연에 가까우면: 판정 범위와 위로 보정을 손보고, 그래도 안 되면 동작 설계를 다시 본다.
- 1이 안정적이면: 3(저장·로그)으로. 보이는 콘텐츠는 바닥을 깐 뒤에 올린다.

## 5. 구현 모델에 맡기는 단위

한 번의 요청에는 작업지시서의 한 단계(A~G)만 준다. 단계 A는 **코드를 고치지 않는 조사**이므로 결과를 받은 뒤 B로 넘어갈지 정한다. 이후 요청에는 해당 단계 범위, 직전 테스트에서 발견한 문제, 실행·테스트 방법을 함께 전달한다.
