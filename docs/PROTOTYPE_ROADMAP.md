## 1. 지금 위치

**기준 코드는 `physics_playground`.** v3 단계 A~G 완료, v4 단계 **H-0~H-2 완료, H-3 진행 중, H-4 대기** (2026-10-30). 판정은 혼합 구조로 이미 옮겨졌고 2인·200ms 검증이 통과 중(D 54/0, E 110/0). 남은 건 검증 강화 4개(튜닝 서버 소유, 이동 보정, 잡힌 몸 서버, 리스폰 서버).

`PLAYTEST_01`은 다른 프로젝트(RPG 폴더) 기록이다. 그쪽의 사로·방패·횡베기는 4단계(전투 기본)에서 참고한다.

## 2. 전체 진행 순서 (기획서 v0.6, 2026-10-30)

놀이터 이후 알파까지 약 10~12주 (Claude Code 기준 추정). 10-29 리뷰에서 **20주 전후가 현실적**이라고 봤다. 각 단계 들어갈 때 재산정.

| 단계 | 구현 범위 | 넘어가는 기준 | 목표 (10/30 기준) |
| --- | --- | --- | --- |
| 1. 물리 놀이터 마무리 | v4 H-3(지구력→HP·스태미나) → H-4(종족 선택대, 주먹·발차기, 기술 슬롯 구조, 무기 선택대 서버 승인) → 손맛 확인 12문항 | "설계하지 않은 무브가 몇 번 나왔나" | ~11/6 |
| 2. 네트워크 검증 강화 (1주) | 튜닝 값 서버 소유 · `_check_move` 경고→보정 · 잡힌 사람 위치 서버 소유 · 리스폰 서버 선택 | A가 B를 던져 낙사·리스폰이 양쪽 화면에서 같음, D·E 200ms 무회귀 | ~11/13 |
| 3. 저장·사건 로그 (1~2주) | Supabase 계정·캐릭터 저장·재접속 보존, 모든 행동 기록 (추가만) | 재접속해도 상태 보존, 로그 누락 없음 | ~11/27 |
| 4. 전투 기본 (2주) | 검·방패·맨손 평타, 몬스터 AI, 드랍, **레벨·경험치(지수 곡선)**, 숙련(명중 × 상대 레벨), **방어력 공식·장비 수치**, 보스 1, 난이도 다른 지역 2개 | 최초 토벌·최초 도달이 연대기에 남는다. **여기서 "첫 게임" — 친구 2~3명 내부 테스트** | ~12/11 (현실 12월 말) |
| 5. 세계 규칙 (1~2주) | 최초 획득(DB 유일 제약), 세계 플래그 + GM 수정, 조건 엔진, 연대기 | | ~12/25 |
| 6. 개인화 히든 (1~2주) | 플레이어 프로필 계산, 같은 장소에서 사람마다 다른 히든 | 두 사람이 다르게 플레이한 뒤 같은 동굴에서 각자 다른 것을 발견한다 | ~1/8 |
| 7. NPC 사회 (2~3주) | 마을, 말풍선·귓속말, ??? 이름·지식, NPC 태도. 뒤에 **농사**(심기·가속 성장·수확·NPC 판매·농기구, 구현량 적을 때만) | | ~1/29 |
| 8. 알파 콘텐츠 → 알파 | 봉인 이야기, 테스터 5명 | | 2월 초 (현실 3월 중순) |

**실제 진행 순서는 1(H-3 → H-4 → 손맛 확인) → 2 → 3 → …** 이다. 1·2의 상세는 v4 지시서의 단계 H와 진행표를 따른다. 2단계 지시서는 H-3 보고 뒤에 쓴다.

| v4 단계 | 상태 | 로드맵 위치 |
| --- | --- | --- |
| H-0 영향 조사 | 완료 | 1 |
| H-1 능력치 스케일·종족 데이터 (+ 서버 소유) | 완료 | 1 |
| H-2 버티는 힘 삭제 + 넉백 허용치 | 완료 | 1 |
| H-3 지구력 → HP·스태미나 (전제: 능력치는 레벨로 오름) | **진행 중** | 1 |
| H-4 종족 선택대 + 주먹·발차기 + 기술 슬롯 | 대기 | 1 |
| N 검증 강화 4개 | 대기 (지시서는 H-3 보고 뒤) | 2 |

## 3. 전투 기본 지시서에 들어갈 입력 (4단계, 아직 안 씀)

오늘(10-30) 확정된 수치 쪽 뼈대. 4단계 지시서 쓸 때 이걸 그대로 옮긴다.

- **레벨**: 경험치는 몬스터 처치. 필요 경험치 지수 곡선(상한 없음). 레벨업이 체력·근력·지구력·민첩·지능을 올린다 (어느 능력치가 얼마나는 미정). 레벨업 연출은 일상 보상, NPC가 알아보는 건 마디(100레벨 등)에서만.
- **숙련**: 기술을 **명중**시킨 횟수. 상대가 자기 레벨보다 한참 약하면 거의 0, 비슷하면 최대, 높을수록 더. 기술은 스태미나를 쓴다. 수치 상승폭은 작게, 해금(재시전·밀림 감소·캔슬)이 몸통.
- **고레벨 판정**: 숙련으로 얻는 능력 상승 효율이 레벨로 얻는 효율을 넘는 교차점 (고정 숫자 아님).
- **방어력**: 캐릭터 스탯 아님, 장비에만. `피해 = max(0, 공격력 − 방어력×5%) × 100/(100+방어력)`. 방어 400이면 공격력 20 이하 = 0. 5%는 쪼렙 무적 범위 손잡이. UI: 방어력 숫자, 마우스 올리면 감소율. 갑옷은 무게 있음. 전설급에 방관 옵션.
- **돈**: 몬스터 드랍(가죽 등) 판매, 어쩌다 장비 드랍. NPC 상점에서 기본 장비·농기구.
- **결투 NPC**: "너.. 강하구나?"는 종합 능력 기준 이상 **또는 레벨 대비 강함**으로 판단.

## 4. 알파 이후로 미룬 것

에프렌 본편, 와일드 오크족, 마녀, 소용돌이 유적, 전직 트리, 활·스태프, 국가·전쟁·항해, 로아풍 아트, 여러 마을 간 소문 전파, 집·결혼·가족·플레이어 간 거래(농사는 조건부 알파), 히든 그래픽 다운로드, **피니메스 시작마을 습격 사건**(정식 오픈 후, 호감도 높은 접속자 N명 이상일 때 패치로), **파티 따라 하는 스켈레톤 방**(사건 로그로 행동 패턴 재생), 맷집 숙련(보류).

## 5. 테스트 결과에 따른 판단

- 지연 200ms에서 이동이 답답하면: 콘텐츠 추가 전에 보간·검사 여유를 고친다.
- 튕겨나감 기준이 납득 안 되면: `tolerance_per_strength`만 조정, 공식은 유지.
- 종족 차이가 체감 안 되면: `ratio_k_jump/ratio_k_speed` 2배 비교 (손맛 Q12).
- 밀치기·던지기 협동이 우연에 가까우면: 판정 범위와 위로 보정을 손보고, 그래도 안 되면 동작 설계를 다시 본다.
- 4단계(전투 기본) 끝나고 손맛이 없으면: 5~7로 가지 않는다. 전투를 먼저 고친다.
- 1이 안정적이면: 2(검증 강화)로. 보이는 콘텐츠는 바닥을 깐 뒤에 올린다.

## 6. 구현 모델에 맡기는 단위

한 번의 요청에는 지시서의 한 단계(H-3, H-4, N…)만 준다. 단계 보고를 받은 뒤 다음으로 넘어갈지 정한다. 요청에는 해당 단계 범위, 직전 테스트에서 발견한 문제, 실행·테스트 방법을 함께 전달한다.
