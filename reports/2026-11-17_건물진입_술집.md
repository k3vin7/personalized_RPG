## 2. 건물 진입: 소속 방식

처음에는 위치 계산과 셰이더로 만들었다가 버그가 반복돼서 "소속" 방식으로 다시 짰다.

### 구조

```
pub (Building)
├─ storey_b1, storey_1, storey_2, storey_3   (BuildingInterior)
│    ├─ rooms/  doors/  holes/        손으로 놓는 표시 상자
│    ├─ walls/  floor/  rails/        생성기가 만든 실제 노드
│    └─ lights/  furniture/  pillars/
├─ stair_b1, stair_1, stair_2                (BuildingStair)
└─ 지붕, 박공, 굴뚝
```

### 규칙

| 무엇 | 규칙 |
|---|---|
| 내가 어디 있나 | 발밑에 있는 것이 속한 곳. 계단 위면 아래층, 계단참이면 위층. |
| 무엇을 그리나 | 내가 있는 층의, 내가 있는 공간과 그 공간의 계단. 다른 층·지붕·건물 밖은 안 그린다. |
| 공간 | 문 없이 트인 방들의 묶음. 방 상자에서 자동 계산한다. |
| 공간이 바뀌는 때 | 몸이 문을 완전히 지났을 때. |
| 문 너머 | 옆 공간(또는 건물 밖) 바닥이 띠 모양으로 보인다. |
| 클릭 | 땅만 눌린다: 내 공간의 바닥, 그려진 계단, 문 너머 띠. 벽·가구·잘린 벽 윗면은 통과. |
| 다른 사람 | 같은 층, 같은 공간에 있을 때만 보인다. 밖에서는 전부 보인다. |
| 카메라 쪽 벽 | 0.5 m만 남기고 자르고 어두운 뚜껑을 덮는다. |

전부 내 화면에서만 일어난다. 충돌과 위치는 두 화면이 같다.

### 파일

- `scripts/world/building_interior.gd`: 층. 생성기(벽·기둥·창문·띠·목골·바닥·난간·횃불)와 화면용 함수.
- `scripts/world/building_stair.gd`: 계단. 경사로 충돌 + 보이는 계단 + 위층 바닥 구멍 표시.
- `scripts/world/building.gd`: 건물. 길찾기 지도가 준비되면 스스로 검사하고 `BUILDING_CHECK`를 찍는다.
- `scripts/camera/interior_view.gd`: 내 화면만 바꾸는 쪽.
- `scripts/player/player_movement.gd`: 클릭 규칙, `CLICK landed=...` 출력.
- `scripts/tests/bi_checks.gd`: 두 화면 검사(`--auto-only=BI`).

## 3. 술집 배치

- **지하**: 창고 계단으로 내려간다. 술통 8개.
- **1층**: 홀(탁자 3줄, 벽난로, 기둥 2개, ㄱ자 바와 2 m 통로), 주방, 창고, 서쪽 날개(계단실, 단체석). 앞문은 서쪽, 뒷문은 동쪽(창고).
- **2층**: 계단실 → 통로 → 남북 복도. 객실 서쪽 4칸, 동쪽 2칸, 동쪽 가운데 휴게 자리.
- **3층**: 계단실 → 동서 복도. 객실 남쪽 2칸, 북쪽 2칸.
- **겉모습**: 층마다 0.4 m 내밀기, 45도 박공 지붕 셋, 굴뚝, 목골(세로 샛기둥+가로대), 창문 1층 4개·2층 8개·3층 7개.
